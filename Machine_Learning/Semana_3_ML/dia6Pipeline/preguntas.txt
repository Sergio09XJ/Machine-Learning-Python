¿Qué problema resuelve Pipeline?
-El flujo de trabajo al entrenar el modelo, verificarlo y la prueba final. 
¿Qué sucede cuando ejecutas fit() sobre un Pipeline?
-Cada paso en el pipeline toma como resultado el anterior. Al hacer fit en un pipeline se entrena el modelo 
 si se usa Scaler, entonces primero escala los datos de Train, conserva la info de Mu y Sigma y después entrena el modelo

¿Qué sucede cuando ejecutas predict()?
-Escaler transforma los datos ingresados de X_valuacion o X_test usando Mu y Sigma del proceso anterior y 
con el resultado pasa a predecir el modelo con los datos ya escalados. 

¿Por qué el escalador no debe ajustarse con Validation?
-Porque es daría entonces el entrenamiento estaría incompleto por que de ahí se basa para obtener Mu y Sigma.

¿Qué ventaja tiene combinar Pipeline con Cross-validation?
-Hace el trabajo mucho mas facil y correcto, automaticamente entrena cada fold y evalua 
 y para cada fold elimina los datos anteriores. 

¿Qué diferencias encontraste entre la implementación manual y Pipeline?
-Pipeline hace el trabajo mucho mas rapido y sencillo.
